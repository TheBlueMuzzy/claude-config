# Define — the concept on one page (GDD Part 1)

Goal: one clear concept everyone could explain — what it should feel like, what it is, and what's in scope — locked so Design can build on it.

## Do (one answer per need — "which one is it?")
1. **Read** `.planning/IDEATE.md` (older projects: GDD §1–2 + `research/discovery.md`). What his material already answers shows first, one tap to keep.
2. **Experience targets** — **mda-analyze** targets: §2 (1–2 primaries in players' words, not-this-game, a *watchable* "we'll know when" each, key moments, watch-outs).
3. **Pillars** — 3 in §3, each with the kind of argument it settles.
4. **Pitch** — §1: the story in 3–5 lines written to "you", one line anyone gets, the familiar part and the new part. Offer prior-art research once ("has this been done?"), sourced.
5. **Core loop & play** — §4: the loop in verbs; where it's played first, who with (solo, together, online, by turns, against the computer).
6. **Clash check** — read Part 1 for things that pull against each other (a feeling vs a pillar, a pasted-on theme, a decision with no real trade-off); show each as A, B and why; Muzzy settles them.
7. **Scope** — §5: sort every feature idea into Must (per release stage) · Should · Could · Won't (with why), and pick the vertical slice. Musts for the first release = the smallest version that hits the primary target.
8. **Risks** — §6: the one or two things most likely to stop it being great, and the cheapest test for each (a sketch, a sim, research — Design runs them). §7 Product: the release path, if he knows it.
9. **Lock** — show Part 1 on one page (✓ each chapter, what's still open — Design fills it) and ask: "Lock the concept?" (Not yet — change something · Lock it — on to Design). Locking means Design builds on it; later changes are logged.

## Output
GDD Part 1 (§1–§7) filled. Header: `Current phase: Part 1 locked <date>`. Commit `GDD: define` with STATE.

## Done when
- Pitch is one sharp line · targets locked with watchable signs · 3 pillars set · clashes settled · scope sorted per release with a slice · Muzzy locked it.
